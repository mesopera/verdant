## 📦 Installation

### Prerequisites
- Windows 10 or later
- GitHub account with Personal Access Token (repo scope)

### Quick Start

1. **Download `verdant-engine.exe`** from the Assets section below
2. **Create GitHub Personal Access Token:**
   - Visit: https://github.com/settings/tokens/new
   - Name: `Verdant Engine`
   - Scopes: Check `repo` (Full control of repositories)
   - Generate and copy the token
3. **Run authentication setup:**
   ```powershell
   .\verdant-engine.exe auth
   ```
4. **Install as Windows Service:**
   ```powershell
   # Run as Administrator
   .\verdant-engine.exe install
   .\verdant-engine.exe start
   ```

### Alternative: Run in Foreground
```powershell
.\verdant-engine.exe run
```

## 🎯 Configuration

Configuration file location: `%LOCALAPPDATA%\Verdant\config.toml`

**Example configuration:**
```toml
[schedule]
mode = "aggressive_random"
min_interval_minutes = 30
max_interval_minutes = 180
timezone_optimization = true
turbo_multiplier = 1.0  # Set to 11.0 for TURBO MODE 🚀
```

**Schedule Modes:**
- `gentle` - 1 commit/day
- `balanced` - 2-3 commits/day
- `aggressive` - 4-8 commits/day
- `aggressive_random` - 4-8 commits/day at random intervals (recommended)
- `turbo` - User-defined intensity multiplier
